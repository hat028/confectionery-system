# Управление кондитерской

Информационная система для автоматизации работы кондитерской и пекарни.

Основные функции:
- Управление ассортиментом продукции
- Оформление заказов клиентов
- Учёт ингредиентов и складских остатков
- Управление сотрудниками
- Учёт продаж и формирование отчётов
- Онлайн-заказы
- Доставка заказов
